# ⚡ EdgeTrader – Universal Signal Bot

Automatisierter Trading-Bot der Telegram-Signale direkt auf deinem Broker ausführt.

## Features
- 📡 Telegram-Signale automatisch erkennen und handeln
- 🏦 23 Broker unterstützt (Binance, Bybit, OKX, FTMO, RoboForex, ...)
- ⚙️ Konfigurierbares Signal-Mapping
- 🔒 Testnet & Live Trading
- 📊 Hebel, Kapital und Stop-Loss pro Trade
- 👤 Mehrere Profile
- 🔑 7 Tage kostenlos testen

## Installation
1. `EdgeTrader_Setup.exe` von [Releases](https://github.com/bp-shops/edgetrader/releases) herunterladen
2. Installer ausführen
3. EdgeTrader starten und Einstellungen konfigurieren
